# 成品导出

当前为 5.21.0-rc.1 候选版。JSON 与 PNG 任选一种导入；图片像素与原图一致。

- `房东模拟器Z5.21.0-rc.1.json` / `.png`：完整角色卡，内置世界书、原正则和一个酒馆助手脚本。
- `房东模拟器-单入口脚本.json`：仅导入酒馆助手脚本。用于旧卡时先停用旧脚本组。
- `导入脚本.js`：同一入口的纯 JavaScript。

玩家通过游戏右下角选择原版或二改版。两版数据库保留独立记录，不提供自动合并历史。正式 Release 发布后，入口会在下一次启动时检查更新；当前运行过程不会热替换代码。

原卡请见 `../originals/`；更新、缓存和世界书合并行为见 `../docs/runtime-and-updates.md`。
