# 成品导出

当前为 5.21.0-rc.3 候选版。JSON 与 PNG 任选一种导入；图片像素与原图一致。分发及本轮验证结果以 [测试记录](../docs/testing/README.md) 为准。

- `房东模拟器Z5.21.0-rc.3.json` / `.png`：完整角色卡，内置世界书、原正则和一个酒馆助手脚本；包含版本选择面板，已移除大富翁、分基地相关变量、规则和开场说明。
- `房东模拟器-单入口脚本.json`：仅导入酒馆助手脚本。用于旧卡时先停用旧脚本组。
- `导入脚本.js`：同一入口的纯 JavaScript。

右下角选择原版或二改版游戏模式；两版数据库保留独立记录，不提供自动合并历史。左下角 **版本与更新** 选择“跟随最新正式版”或固定某个发布版本，首次展开自动刷新目录。公开候选版仅供手动选择，草稿不进入列表；入口默认版本与本浏览器已知版本也可选择。

点击“保存选择并刷新”后，入口先检查所选包，再保存本角色的选择并重新加载本卡功能，保留当前角色和聊天。请先保存编辑；切换不会回退聊天记录或存档。默认跟随正式版会在下次入口启动时检查更新，游玩途中不热替换运行代码。

`rc.1` / `rc.2` 玩家需要先导入本版完整卡或替换本版入口，取得版本面板。以后兼容当前更新格式的普通脚本和官方世界书更新，无须重新导入卡。正则、首条开场、人物资料与未来更新协议变化，仍可能需要新版完整卡或入口。

新版开场需要导入完整卡并新建聊天。仅更新脚本不会替换旧聊天开场，也不会主动清除旧存档中的已停用字段；世界书合并保留玩家修改，冲突内容需要玩家自行取舍。

原卡请见 [originals](../originals/)；操作步骤见 [版本选择说明](../docs/version-selection.md)，缓存和世界书合并行为见 [运行与更新说明](../docs/runtime-and-updates.md)。

目录只保留当前候选卡；旧候选版仍可从对应 Git 标签取回。
