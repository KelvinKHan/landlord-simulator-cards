# 成品导出

当前为 5.21.0-rc.2 候选版。JSON 与 PNG 任选一种导入；图片像素与原图一致。

- `房东模拟器Z5.21.0-rc.2.json` / `.png`：完整角色卡，内置世界书、原正则和一个酒馆助手脚本；已移除大富翁、分基地相关变量、规则和开场说明。
- `房东模拟器-单入口脚本.json`：仅导入酒馆助手脚本。用于旧卡时先停用旧脚本组。
- `导入脚本.js`：同一入口的纯 JavaScript。

玩家通过游戏右下角选择原版或二改版。两版数据库保留独立记录，不提供自动合并历史。正式 Release 发布后，入口会在下一次启动时检查更新；当前运行过程不会热替换代码。

新版开场需要导入完整卡并新建聊天。仅更新脚本不会替换旧聊天开场，也不会主动清除旧存档中的已停用字段；世界书合并保留玩家修改，冲突内容需要玩家自行取舍。

原卡请见 `../originals/`；更新、缓存和世界书合并行为见 `../docs/runtime-and-updates.md`。

目录只保留当前候选卡；旧候选版仍可从对应 Git 标签取回。
