# 源码

`legacy/` 是从原卡提取的内部模块，文件编号对应旧版分析中的 S 编号。单入口运行时只装载选定版本的模块；无需在酒馆助手中逐个导入。当前 5.21.0-rc.2 保留原版与二改版，按作者要求移除大富翁及其分基地变量；S03 旧切换器、S24 大富翁没有纳入开发源码。

`runtime/` 管理依赖、生命周期、聊天/分支失效、串行世界书更新及消息重绘状态。`updater/` 负责正式版本与官方世界书内容更新。

`content/worldbook.json`、`regex.json` 用于构建新版。`baseline-5.20.json` 是更新合并所用的原始基线，后续改世界书时不要跟着覆盖它。其中的大富翁和分基地旧内容用于识别作者删除的段落，不是当前初始化或提示词配置；清空基线会影响旧卡升级时的三方比较。

`content/first-message.txt` 是新卡首条开场来源，导出时同步顶层和 `data.first_mes`，并保留原换行。新导出的首条开场同步移除玩法说明，详见 [移除范围与旧档边界](../docs/removing-monopoly.md)。运行时不会主动清扫玩家旧存档，也不会通过脚本更新替换旧聊天开场。

运行 `npm run build` 生成 `dist/` 和 `exports/`。不要直接编辑构建产物；内部模块的自由全局变量由构建器定向到各自资源作用域，使旧版代码可以保留独立脚本语义。
