# 源码

`legacy/` 是从原卡提取的内部模块，文件编号对应旧版分析中的 S 编号。修复以保留原有玩法与界面为前提。单入口运行时只装载选定版本的模块；无需在酒馆助手中逐个导入。

`runtime/` 管理依赖、生命周期、聊天/分支失效、串行世界书更新及消息重绘状态。`updater/` 负责正式版本与官方世界书内容更新。

`content/worldbook.json`、`regex.json` 用于构建新版。`baseline-5.20.json` 是更新合并所用的原始基线，后续改世界书时不要跟着覆盖它。

运行 `npm run build` 生成 `dist/` 和 `exports/`。不要直接编辑构建产物；内部模块的自由全局变量由构建器定向到各自资源作用域，使旧版代码可以保留独立脚本语义。
