# 16 个世界书条目

这里的“常驻”表示配置为 constant，仍受酒馆是否启用本书、提示词预算及插件设置影响。“深度 0”是 system 消息插入位置。角色卡导入时，`extensions.position` 优先于外层 `position`；因此 W01–W03、W14 应按深度插入理解。依据：[SillyTavern 导入实现](https://github.com/SillyTavern/SillyTavern/blob/8172dcd0ee672d3cd9a5e5f7af134f91a45cd2b8/public/scripts/world-info.js#L5510)。

全部条目的概率为 100；未设定有效的黏着、冷却、延迟效果。完整的递归、预算、大小写等标志以 [inventory.json](inventory.json) 为准。关键词条目的扫描深度均为 1，因此实际发送的触发短语十分重要。

## 初始化与世界观不是同一步

W00 初始化数值和列表；W05 描述世界背景；开场白生成初次情节和补丁；S23 可更换开场白与聊天世界书。这四者不能互相替代。

这份卡的默认 first_mes 是使用说明，没有初始情节补丁。`alternate_greetings[0]` 是空公寓开局，只有 4 条时间 replace；`alternate_greetings[1]` 是六租客开局，含 23 条补丁，增加 8 个房间、6 位租客和用户物品/资金。它还再次追加 W00 已有的“地下一楼”，会形成重复楼层；六位租客的固定 ChatLore 档案并没有随开场补丁创建。

当前 MVU 初始化实现读取启用的全局世界书以及角色主/附加世界书，遍历其中名字含 `[initvar]` 的条目；不能把“启用的世界书”与“启用的条目”混为一谈。依据：[MVU 初始化源码](https://github.com/MagicalAstrogy/MagVarUpdate/blob/61010dab47bc3a08a1b626320bf7fc8c9573eca4/src/function/initvar/variable_init.ts#L230)。

## EJS 与宏

本卡的世界书、脚本、正则替换模板和开场中未发现 `<%` EJS 代码标记，常规系统提示词字段为空，`xiaobaix-tasks.tasks` 也为空。现有的 W03 用酒馆助手变量宏，W12/W15 用酒馆变量宏；不能仅凭出现双大括号就认定需要 EJS。

酒馆助手的 `get_message_variable` 会定位具有变量的消息并读取路径，在发送提示词时替换。依据：[宏实现](https://github.com/N0VI028/JS-Slash-Runner/blob/8e0f4324e7d051025a333831411f03bd3145fac8/src/function/macro_like.ts)、[提示词替换入口](https://github.com/N0VI028/JS-Slash-Runner/blob/8e0f4324e7d051025a333831411f03bd3145fac8/src/panel/render/macro_like.ts)。用户实际全局预设是否使用 EJS 不在这份导出里，仍需运行环境核实。
