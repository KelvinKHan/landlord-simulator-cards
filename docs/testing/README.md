# 测试与验收

当前候选版 `5.21.0-rc.5` 已通过 31 项逻辑/导出测试、52 项 Chromium 联调，以及原卡基准校验。本轮新增版本悬浮球的拖动、点击、位置记忆、根页面滚动、触摸取消和共享显示层清理回归。真实酒馆结果以 [记录](real-sillytavern.json) 的执行时间及版本为准。

自动检查使用 Node.js 24、Python 3 和 Chromium。开发依赖固定在 `package-lock.json`：Babel parser/traverse、esbuild、Playwright、fake-indexeddb、jQuery、lodash、Zod。没有新增玩家需要自行安装的脚本依赖。

```sh
npm ci
npx playwright install chromium
npm run check
npm run test:integration
```

`npm run check` 包含构建、逻辑/导出测试、真实 Chromium 中的隔离酒馆接口联调以及原始 JSON/PNG 的 SHA-256、CRC 校验。

自动覆盖：依赖慢启动和取消、队列失败恢复、聊天切换、连续版本切换、监听不累积、两个手机会话同时同步、不同模块更新同一本世界书、撤回空会话、消息与摘要事务、响应体取消、失败重试不重叠、分析批次失败不提前推进进度、候选人选择/档案编辑在原生重绘后保留、正式版筛选、更新文件损坏、缓存回退、世界书冲突保留与未完成事务恢复、JSON/PNG 一致和未知字段保留；另覆盖新开局无已取消玩法状态、只删除指定规则及开场、Z5.20/rc.1 旧世界书升级删除默认残留且保留玩家改动。

此前增加卡内自动/固定版本、公开版本目录与缓存清单校验、低版本固定、离线返回自动跟随后联网恢复、所选脚本/世界书一致、保存前预下载且不改当前游戏、生成/编辑/聊天切换期间保护、提交后延后生效提示、首次失败回到入口版本、旧启动迟到不破坏新实例，以及窄屏控件与监听/定时器清理。

此前新增：87 个内置 SVG 逐个解码、完全阻断外部图标服务后真实模块仍显示图片；默认窄窗、四角拖拽、缩窗、晚注册和极小视口下功能按钮可用；复现酒馆零高度且有变换的 HTML 根元素，确认两个入口都在可见范围、不会挡住聊天输入、销毁后清理完整。

本轮新增：版本球拖动不误开、微小移动仍算点击、键盘开关、刷新/重挂载后位置记忆、四角/窄窗/缩窗适配、生成中仍可拖动、存储受限容错、pointercancel/capture 丢失清理，以及真实根页面滚动后位置稳定；版本/模式共享显示层各自移除互不破坏，最后移除时清理完整。

`npm run test:integration` 在 `.local/sillytavern-test/` 使用固定提交的真实 SillyTavern 和酒馆助手，每次使用系统分配的独立端口和全新测试数据，确认本次子进程成功启动后才访问，测试结束自动关闭自己的服务；不会误连作者正在使用的 8776 预览。它从本地产物模拟项目 CDN，MVU/Zod 依赖使用固定提交的真实 CDN 构建；不接触个人酒馆配置。首次运行会下载隔离依赖。

[真实酒馆检查结果](real-sillytavern.json)记录版本与执行结果：一个角色脚本、原版/二改版启动、游戏内模式按钮、真实开场右划、MVU 变量改变、工坊更换开场、内嵌正则与状态占位符参与的档案重绘，以及无运行错误、无付费模型调用。

## 作者手动验收

1. 导入候选卡，确认酒馆助手角色脚本只有“房东模拟器 · 单入口”。
2. 用原版打开公寓和手机，再切二改版，确认界面切换且没有多份浮窗。
3. 在测试聊天中生成卧室、招募候选并选择一个人，编辑档案后等待一次页面重绘，确认选择与编辑仍在。
4. 保存档案、办理入住，检查卧室与住户显示；用手机发送消息后查看 ChatLore 摘要，撤回至空后确认摘要移除。
5. 发起副 API 请求时切换到另一段测试聊天，确认旧结果不会写进新聊天。
6. 使用工坊替换测试开场，确认文字与 MVU 状态一起更新。两套手机数据库沿用原设计，不据此验收跨版本历史迁移。
7. 拖动紫色“版本”悬浮球，点击展开“版本与更新”，先固定当前版本保存并刷新，再恢复跟随最新正式版。确认球的位置和版本选择持久化、原版/二改版模式保持且仍只有一条脚本；生成中不能执行版本切换。
8. 在窄窗口打开菜单，确认公寓、手机、工坊图标可见；拖动主球到窗口边缘，确认所有功能仍能点击。
9. 在新卡新建聊天，确认首条说明、内置世界书和新变量中没有大富翁/分基地。旧存档不做主动擦除；玩家改过的条目出现更新冲突时保留原文，具体边界见 [清理说明](../removing-monopoly.md)。

真实模型内容、主模型生成完整流程、EJS 插件参与的提示词构造，以及用户现有插件组合没有使用真实配额测试。本轮不会对这些未测范围作通过承诺。

## 分发检查

[作者预览实测](live-preview.json)记录 8776 页面直接使用公开 CDN 的结果：rc.5 版本球可拖动，拖动后点击能展开更新面板，刷新并重新进入聊天后球的位置保持。该次实测遇到 GitHub 匿名 API 临时限流（HTTP 403、剩余额度为 0），因此公开目录和最新正式版检查暂不可用；当前已验证的候选版与悬浮球照常运行。此限制与隔离联调模拟版本目录的通过结果分开记录。

[GitHub Actions 记录](github-actions.json)、[公开 CDN 检查](cdn.json) 均注明所验证的版本或提交号。CDN 核验确认入口、运行包、世界书内容包、清单及 JSON/PNG 六份文件均返回 HTTP 200、允许跨域，并与本地已验收文件逐字节一致。

候选标签用于作者验收，不会作为正式 Release 自动更新玩家。自动集成会关闭自己的服务；作者正在使用的 8776 预览独立保留。隔离环境位于忽略提交的 `.local/`。
