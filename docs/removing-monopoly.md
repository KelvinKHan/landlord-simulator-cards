# 大富翁移除范围

作者于 2026-09-07 要求删除当前开发版中的大富翁相关内容。`5.21.0-rc.2` 在保留原版与二改版选择的基础上完成以下清理：

- 删除 S01 中的大富翁及分基地变量结构。
- 删除世界书初始化条目中的筹码、回合、据点等状态和空分基地，以及更新规则、变量列表中的相关内容。
- 删除新卡顶层和 `data` 中首条开场的大富翁游玩说明。
- S24 大富翁脚本与 S03 旧切换器原本就未纳入新版源码或运行模块，不再保留可启用该玩法的入口。

公寓、手机、地图、工坊及两版租客系统没有依赖被删除的字段；现有正则与两个备用开场不包含该玩法，保持原样。条目 ID、启停设置和其余角色卡字段仍按原值导出。

## 保留内容与升级边界

`originals/` 和 `docs/analysis/` 保留 Z5.20 的历史记录。`src/content/baseline-5.20.json` 保留原始世界书，用于比较“旧官方版本、玩家本地版本、新官方版本”。其中的旧玩法文本是升级依据，不是当前版本的世界书来源，不能随新版一起删掉。

世界书更新会移除未被玩家改动的旧官方段落。玩家改过同一条目的内容时，合并保留本地内容并报告冲突，不强行覆盖；因此这类旧条目可能仍带有玩法文本，需要玩家自行取舍。

运行时不主动擦除旧聊天存档里的大富翁或分基地字段，也不修改旧手机记录。新开局不再生成这两组初始状态，当前模块不再使用它们。仅移除功能不会把原先的分基地租客自动搬入主公寓。

首条开场的改动通过新版完整 JSON / PNG 提供；导入新卡并新建聊天即可使用。脚本和世界书自动更新不会替换已有聊天的开场消息。

`rc.2` 是候选版，不通过正式 Release 自动发现。标签、公开 CDN 以及检查结果以 [验收记录](testing/README.md) 为准。
