# rc.4 图标与入口可见性修复

## 实际故障

在 SillyTavern 1.18.0 / 酒馆助手 4.9.5 的 633 × 696 窗口中：

- Iconify 外链图片已经完成请求，但 naturalWidth 为 0，按钮显示破图。
- 酒馆给 HTML 根元素设置 translateZ(0) 和 perspective；根元素没有文档流高度。原来的底部固定入口因此以该根元素计算位置，版本面板顶部为 -113px，模式面板为 -52px，完全跑出屏幕。
- 浮动主菜单默认位于顶部 100px，三个子按钮一直向上展开，公寓按钮因此超出窗口。

## 修改

87 个实际使用的 SVG 随运行包内置。构建时替换静态地址，天气、工坊和默认图标通过同一函数生成。自定义人物图片保持原行为。上游来源和许可证见 src/runtime/icon-licenses/。

版本与模式面板使用有明确视口高度的独立容器；容器本身不拦截点击，只有面板接受操作。打开聊天、公寓或切换模式后仍可展开左下角版本入口。没有修改酒馆全局样式。

浮动菜单依据窗口空间决定展开方向，窄窗可排列，极小窗口可滚动；缩窗、新按钮加入时重新计算。按钮带名称并支持键盘操作。

## 升级范围

rc.4 的入口面板修复属于 bootstrap 本身，因此旧 rc.1–rc.3 入口需替换一次单入口脚本；无需删除聊天或重新填写 API。普通脚本与官方世界书的后续兼容版本仍可通过卡内版本选择更新。

正则、人物资料和历史聊天不通过本轮修复远程替换。外部人物图片、云端工坊和模型调用仍需要各自的网络连接。

## 验证

31 项逻辑/导出检查、44 项 Chromium 检查及原卡基准校验通过。真实 SillyTavern 回归另外验证窄窗入口可见且可点、输入不被遮挡、断开 Iconify 后公寓图标可显示和操作；具体结果见 testing/real-sillytavern.json。
