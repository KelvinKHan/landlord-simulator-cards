# 在卡内选择版本

从 **5.21.0-rc.3** 起，角色卡左下角提供 **版本与更新**。以后兼容当前更新格式的脚本与官方世界书更新，可以在这里选择，无须每发布一版就重新导入角色卡。

## 第一次升级

正在使用 `rc.1` / `rc.2` 的玩家，需要这一次导入 [rc.3 完整卡](../exports/)，或把原来的单入口脚本替换为本版 [单入口脚本文件](../exports/房东模拟器-单入口脚本.json)，取得版本面板。旧卡原有整组脚本应保持停用，实际游玩仍只启用一条入口。

之后切换到较旧运行版本，左下角面板仍会保留，因为它由入口管理；可随时再通过面板选择可用版本。

## 如何选择

1. 先保存正在编辑的档案、工坊内容等，等待消息生成结束。
2. 展开左下角 **版本与更新**。第一次展开自动刷新列表，随后可用“刷新版本列表”重新查询。
3. 在“更新方式与版本”选择“跟随最新正式版”或一个具体版本。
4. 点击 **保存选择并刷新**。入口先读取并校验所选版本；成功后保存选择，重新加载本卡功能并关闭当前功能窗口，当前角色和聊天保持打开。
5. 等待本卡功能重新出现后，检查面板标题中的实际运行版本。若遇到失败，面板会显示原因及当前状态。

| 选择 | 后续行为 |
| --- | --- |
| 跟随最新正式版 | 每次入口重新启动时检查正式发布，游玩途中不热替换代码 |
| 固定正式版本 | 后续启动继续使用该版本，直到主动改变选择 |
| 固定候选版本 | 主动试用公开候选版；候选版不会自动推送给跟随正式版的玩家 |

列表包含公开已发布的版本。未发布草稿不会出现在公开目录中；入口默认版、当前运行版、本角色已验证版及已固定版会另外保留为选项。因此，`rc.3` 入口默认版可直接选择，无需等待正式发布。暂时读取不到目录时，已有选项仍保留。

右下角的 **原版 / 二改版** 控制玩法实现，左下角控制软件发布版本，两个选择分别保存。发布版本偏好按当前角色的头像标识存在本浏览器中，同一角色的聊天共用；其他设备、浏览器或清除浏览器数据后不会自动同步。

## 更新范围

| 内容 | 行为 |
| --- | --- |
| 脚本功能与修复 | 加载所选版本的运行包 |
| 官方主世界书 | 合并所选版本的官方条目，保留玩家本地修改与冲突 |
| 正则、首条开场、人物资料 | 当前不远程替换；需要这些改动时仍使用新版完整卡 |
| 聊天记录、手机记录、MVU 存档 | 不随版本切换回到过去，也不在原版与二改版间自动合并 |

切回旧版本只切换脚本与官方世界书；已经产生的存档变化仍然存在。较旧脚本能否正确处理较新存档，需要对应版本验证。当前支持清单 `format: 1`；未来若改变入口协议，仍可能需要更新入口一次。

## 失败后如何处理

保存前读取或校验失败时，面板显示错误，原选择及当前游戏继续保留。已选择的版本在启动时失败，入口先恢复本次世界书修改，再尝试本角色上次成功运行的版本；缺少可用缓存时尝试入口默认版。原来的固定偏好仍保留，下次启动继续尝试，玩家也可以主动改选。

正常跟随正式版时，目录偶然返回较低版本不会自动降低已成功使用的较高正式版。主动从固定版本改回“跟随最新正式版”则允许切换到实际最新正式版。

浏览器缓存不能保证完全离线运行，初次入口及部分上游依赖仍需联网。当前版本的检查结果和分发状态见 [测试记录](testing/README.md)，实现细节见 [运行与更新说明](runtime-and-updates.md)。

已验证的酒馆助手使用官方重载脚本接口，保留酒馆主页面和当前聊天；极旧助手缺少该接口时才回退为整页刷新，可能需要重新打开角色。
